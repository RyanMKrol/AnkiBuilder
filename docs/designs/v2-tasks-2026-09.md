# v2 task list

The execution checklist for [v2-goals-2026-09.md](./v2-goals-2026-09.md). Ordered by dependency: each
stage assumes the ones above it. One task is one branch and one commit, per golden rule 4.

Mark a task `[x]` only when its branch is merged, not when the code is written.

## Stage A: v1 maintenance on `main`

These two land on `main`, not `v2`, because they touch v1 docs and tracked deck data.
`V2-MIGRATION.md` forbids `v2` from modifying `output/` or `.anki-builder/`, so doing them on `v2`
would diverge the branches in exactly the data that rule protects. `v2` merges `main` afterwards.

- [x] **A1. Record the `vocabCoverage` book coupling in LIMITATIONS.** Its existing entry covers the
      INFO tier, the false positives and the missing chapter cache, but never says the check is scoped
      to one publisher's CSS class, so on any other book it reports zero misses and prints clean. This
      is the one finding from the v2 scoping that is otherwise unrecorded.
- [x] **A2. Delete chapter 17.** Never delivered (its five ids in `deliveredCardIds` are collisions
      with earlier units, exactly the five backward-dedup excluded), `reviewed: true`, no `done`, no
      audio, no extras sibling. Removes `output/epubs/<book>/chapter-17/` and the dedup entry
      `.anki-builder/epubs/<hash>/corpora/39.json`. **Deleting under `output/` is a human step per
      CLAUDE.md: prepare and hand off, do not self-serve.** Then merge `main` into `v2`.

## Stage B: clear the ground

Cheap, low risk, and they touch code later stages would otherwise have to touch twice.

- [~] **B1. DROPPED: delete the 13 SPENT one-off migration scripts.** Attempted and reverted. The
  repo has an explicit, tested policy of keeping them: `test/scripts/spentMigrations.test.js`
  enumerates all 13 and asserts each carries a dated `SPENT` header, and its own docstring says
  the marker is a header "rather than a `scripts/migrations/` folder, because moving the files
  would break every doc reference". Deleting is a stronger version of the move it declined, and
  it broke two guards: eight docs name these scripts, and
  `test/docs/docsIntegrity.test.js` requires every `scripts/` path named in a doc to exist. This
  task was written without noticing the convention existed.

- [x] **B2. Consolidate the unit-directory regex.** `^(chapter|lesson)-\d+(-extras)?$` is retyped in
      seven places (`audit/units.js`, `review/gateState.js`, `deck/deckFileName.js`, `deck/rebuild.js`
      and three scripts). Export one constant; each copy site already carries a "keep these in step"
      comment admitting the duplication.
- [x] **B3. Remove the silent language defaults.** `?? "ja"` appears in four audit checks and the eval
      fixtures. Make the language an explicit argument, and give `extrasTools.js` a language parameter
      instead of doing Japanese logic (`か$`, a particle set) with none.

## Stage C: foundations

Everything after this depends on these five. They are cheapest now and expensive to retrofit.

- [x] **C1. Split `book.json` into `invariants` and `hints`.** `invariants` are facts code may branch
      on (label decoding, lesson-to-spine mapping, image path resolution); `hints` reach prompts only.
      Enforce the split with a test, so a hint can never become a silent code dependency.
- [x] **C2. Agent role format, with mandatory pinning.** Every role declares `model` and `effort`; a
      role file with no pin is a build error, not a default. Adversary roles pin above the roles they
      check. Overridable by `ANKI_BUILDER_<ROLE>_MODEL`, never at the call site.
- [x] **C3. Structured run report + artifact verification.** Each step emits status, model, effort,
      duration, counts in and out, and its artifact path. Provide the helper the main thread uses to
      verify a phase from the report **and** the artifacts, never from logs.
- [x] **C4. As-generated corpus snapshot.** An immutable per-unit snapshot the review cannot touch.
      The learning pass is worthless without it, and it must exist before anything writes a corpus.
- [x] **C5. Promote `itemSetDiff` out of `src/evals/`.** It is already the right merge primitive
      (normalized `target`, then `english`, never model-authored ids). Stage E's union reconciler and
      Stage G's learning pass both need it.

## Stage D: scripts stop judging

- [x] **D1. Table dump script.** Emit every `<table>` in a chapter with its markup context. No
      decision about which are vocabulary.
- [x] **D2. Image dump and verdict persistence.** Extend the existing image extraction, and add the
      storage for a per-image verdict. Today `extractChapterViaLlm` returns
      `{items, coverage, imageCoverage}` and `epubLlmCorpus.js:22` destructures away all but `items`,
      so a skipped table and a chapter with no table are indistinguishable.
- [x] **D3. `chapterOutline` generality pass.** The `enum`/`wnum` marker knowledge moves to `hints`.
      Keep its exemplary property: an empty result reads as "this book does not number things", never
      "there is nothing here".

## Stage E: phase 1, base vocabulary

- [ ] **E1. Table specialist agent.** Fed by D1. Reports which tables it judged non-vocabulary, and why.
- [ ] **D4 (moved). Retire `vocabCoverage`'s `class="voca"` parsing.** Was in Stage D; it is blocked
      on E1 and a free shadow run proved why. Measured across all 17 base units, a deterministic
      all-tables replacement finds 781 candidate headwords against the selector's 705, but the extra
      76 are mostly false positives (`い-adj.`, a numbered example sentence, `〜です` placeholder
      forms) and it introduces its own false negatives: in chapter file 15 the numbers chart puts the
      digit in column 0 and the reading in column 1, so a "first cell is the headword" rule finds
      none of it, and `ゼロ ／ れい` needs splitting before `れい` is even visible. `ゼロ` and `よん`
      are carded; `れい`, `し`, `しち`, `く` are not, in the whole deck. Which table is vocabulary,
      which cell is the headword, and whether one cell holds two readings are all judgements, which
      is what E1 is for. Retire the selector when E1 can replace it, and close the A1 limitation then.

- [ ] **E2. Chapter reader agent.** Fed by the bounded chapter text. Finds vocabulary independent of markup.
- [ ] **E3. Image specialist agent.** Fed by D2. Emits a verdict per image whatever the verdict is.
- [ ] **E4. Union reconciler.** Unions E1-E3 on C5's matcher, then dedups. Union for existence; never
      majority vote, because in a recall task the minority report is what you want to keep.
- [ ] **E5. Coverage adversary.** Higher model. Sees the chapter, **not** the corpus and **not** the
      extraction prompt. Enumerates independently; the diff happens in code.
- [ ] **E6. Base phase script.** Wires D1-D3 and E1-E5 into one ordered script ending at the base
      corpus review with a watcher armed.

- [ ] **E7. Shadow-run phase 1 against already-reviewed chapters.** The book has 33 reviewed units,
      and a reviewed corpus is a human's own answer to "what should this chapter have produced". Run
      phase 1 over chapters that already have one and diff with `itemSetDiff` (`src/cards/`): items
      v2 found that the reviewed corpus lacks are candidate gaps in v1, items the reviewed corpus
      has that v2 missed are regressions in v2, and both are worth reading before the first real
      build. The cheapest validation available, because the ground truth is already paid for.
      **It must never write into `output/` or `.anki-builder/`**: those hold the very corpora it is
      judged against, and `V2-MIGRATION.md` forbids the `v2` branch from touching them; copy a unit
      to a scratch directory outside the repo. Partial runs come earlier and are worth taking: D4
      gives a free deterministic one with no model calls, and E1 to E3 can each be diffed alone.

## Stage F: phase 2, extras

Miners are unbounded: if the book contains it, it belongs in the extras unit.

- [ ] **F1. Exercise miner.**
- [ ] **F2. Fill-in-the-blank miner.** Every blank resolved; no template reaches a card.
- [ ] **F3. Example-sentence miner.** Key Sentences, model sentences, dialogue lines worth carding.
- [ ] **F4. Gap author.** Driven by `taughtNeverUsed`, the paradigm grid and particle example counts.
- [ ] **F5. Inventive author.** Runs **last**, so it can see what exists and not duplicate it. Bounded
      to about +20% of what the miners produced. Only approved vocabulary and grammar from this
      chapter or earlier.
- [ ] **F6. Extras phase script.** Ordered, F5 last, ending at the extras corpus review.

## Stage G: review, audio, learning

- [ ] **G1. Dashboard: a second corpus stage and a third gate.** The stage names `corpus`/`audio` and
      the gate count appear across `stage.js`, `pages.js`, `deckViewChrome.js`, `applyCards.js`,
      `readiness.js`, `gateState.js`, `cli/commands/audio.js` and four audit checks. This is the
      expensive change in the back half; everything else there is reusable as-is.
- [ ] **G2. Audio phase script.** Port `src/audio` verbatim and wire both units into one run.
      **Verify zero TTS re-spend before anything else**: byte-identical `ttsText` means 100% cache
      hits, and any drift re-buys roughly 4,400 clips.
- [ ] **G3. Learning pass.** Diff C4's snapshot against the approved corpus, attribute each reviewer
      change to the role that produced the item, report what that role got wrong.
